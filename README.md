# Covid-Image-Classification
This study investigates the use of **Convolutional Neural Networks** for automated **classification of COVID-19 and Normal medical images**. The primary objective is to develop a model capable of recognizing COVID-related image patterns while maintaining good generalization on unseen data. Particular attention is given to COVID recall because correctly identifying positive cases is important in medical image classification.
The analysis uses 251 RGB images with dimensions of **128 × 128 pixels**. The image labels are converted into binary values, with COVID represented by 1 and Normal by 0. The dataset is divided into training, validation and testing subsets in a 70:15:15 ratio. Before model training, image pixel values are normalized to the range 0–1. CNN models are constructed using convolutional layers for feature extraction, max-pooling for dimensionality reduction and dense layers for classification.
The first model consists of three convolution-pooling blocks and produces **100% training accuracy, while validation accuracy reaches 97.37% with 100% COVID recall**. Although the validation results are strong, the perfect training performance suggests possible **overfitting**. Therefore, a second architecture with reduced convolutional complexity and a lower learning rate of 0.0001 is developed.
The second model achieves 96% training accuracy and 97.37% validation accuracy, with 94.1% COVID recall. Its lower training performance compared with the deeper model, together with strong validation performance, indicates better generalization. The analysis therefore selects the second CNN as the final model. The results demonstrate that model complexity should be carefully controlled when working with small medical image datasets.
